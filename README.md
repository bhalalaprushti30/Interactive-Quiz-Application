📌 Overview :-
The Interactive Quiz Application is a dynamic and user-friendly web-based quiz app that allows users to test their knowledge on frontend development. The quiz presents multiple-choice questions with instant feedback, a scoring system, and a modern UI design.
This project is built using HTML, CSS, and JavaScript, making it an excellent resource for anyone learning DOM manipulation, event handling, and UI styling.

🚀 Features :-
✅ Multiple-choice questions – Each question has four options (A, B, C, D).
✅ Instant feedback – Correct answers turn green, incorrect ones turn red.
✅ Score tracking – Your score updates dynamically after each question.
✅ Modern UI – Styled using CSS3 with a sleek design, including animations and hover effects.
✅ Responsive design – Works smoothly on mobile, tablet, and desktop devices.
✅ Next Question Functionality – Click the "Next" button to proceed.
✅ Dynamic question loading – Questions are stored in a JavaScript array and loaded dynamically.

🎯 How to Use the Quiz :-
1️⃣ Open the application in your browser.
2️⃣ Read the displayed question and select your answer.
3️⃣ Your selected option will be highlighted in green (✅) if correct or red (❌) if incorrect.
4️⃣ Click the "Next" button to move to the next question.
5️⃣ Your score will be updated dynamically.
6️⃣ At the end of the quiz, a completion message will appear.

📌 Code Structure :-
The project consists of three main files:
📂 interactive-quiz-app/
├── 📄 index.html → Contains the structure of the quiz.
├── 🎨 style.css → Adds styling and modern UI effects.
└── 🎯 script.js → Contains quiz logic and question handling.
